# NFL rules corpus

This directory contains original, plain-language explanations of selected rules in effect for the
2026 NFL season. It is intentionally small so retrieval behavior can be inspected and evaluated.

Each document starts with TOML metadata delimited by `+++`. Metadata records the corpus season,
official rule references, and the authoritative source URL. Markdown headings define semantic
sections for deterministic chunking.

The NFL rulebook is not redistributed here. Consult the linked official source when exact rulebook
language or a definitive interpretation is required. This project is independent and is not
affiliated with or endorsed by the National Football League.
