# NFL Rules Explainer

This context describes the language used to explain NFL playing rules from a versioned,
evidence-backed knowledge base.

## Language

**Corpus season**:
The NFL season whose playing rules govern every explanation in a corpus release.
_Avoid_: Current rules, latest rules

**Rule explanation**:
An original, plain-language account of one or more NFL rules, linked to the authoritative source.
_Avoid_: Rulebook copy, source document

**Rule reference**:
The NFL rule, section, and article identifier supporting a rule explanation, such as `8-1-3`.
_Avoid_: Rule number, citation

**Play scenario**:
A description of game events for which a ruling or rule explanation is requested.
_Avoid_: Prompt, hypothetical

**Ruling**:
The conclusion that follows when the corpus contains enough facts and evidence to resolve a play
scenario.
_Avoid_: Answer, prediction

**Evidence**:
The passages from rule explanations used to support a ruling.
_Avoid_: Context, result

**Citation**:
A link from a ruling to its supporting rule explanation and authoritative rule reference.
_Avoid_: Source, evidence

**Abstention**:
The explicit outcome when the corpus or play scenario lacks enough information for a supported
ruling.
_Avoid_: Refusal, fallback
